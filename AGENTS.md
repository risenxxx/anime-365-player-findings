# Для ИИ‑агентов

Если вы агент, которому поручено исправить плеер, читайте в таком порядке:

1. **[README.md](README.md), раздел «Что осталось»** — нерешённые проблемы на текущем коде
   сайта (состояние на 27.10.2026).
2. **[REPORT.md](REPORT.md)** — по каждой: где в коде, как воспроизвести, что показали логи.
3. **[SOLUTIONS.md](SOLUTIONS.md)** — предлагаемые решения. Код там — эскизы, на стенде не
   прогонялись.
4. **[archive/2026-10-25](archive/2026-10-25/README.md)** — только для истории: исходное
   расследование и патчи 01–07 к старой версии кода. К текущему коду эти патчи не
   применяются, но их `.md` показывают формат и проверенные идеи (например, сверку версии
   файла для H5 — патч 03).

## Как переносить правки в исходник сайта

- Текущие версии — в `vendor-manifest.json`: `videojs.concatenate.min.js?1793007100`
  (собственный плагин сайта поверх video.js 4.x, в проде минифицирован),
  `embed.min.js?1793007100`, `sworker.js?27`, `swMain.js?v=27` (движок SW, не минифицирован).
- Код находите по названиям функций (`onError`, `_prepareRecovery`, `_retryRecovery`,
  `_watchStall`, `originFetch`, `originReader`, `saveMetadata`) и строкам логов, а не по номерам
  строк: номера даны по prettified‑копии.
- В `concatenate` минифицированные `v` и `m` — это плеер video.js и состояние плагина
  (`player.concatenate`). В документах они названы `player` и `plugin`.
- После правки `swMain.js` поднимите версию в двух местах сразу: `swMain.js?v=N` в
  `sworker.js` и `/sworker.js?N` в `embed.js`/`main.js` (правило описано в самом
  `sworker.js`).

## Как проверить свою правку

Стенд воспроизводит каждую проблему локально, без сайта (macOS, Google Chrome, Node 20,
ffmpeg), см. «Как запустить локальный стенд» в README. Положите правку как патч в `patches/`
(формат — [patches/README.md](patches/README.md)) и запустите нужные сценарии без окон:

```sh
node runner/run.mjs --headless --patched=all h1-outage-nosw h2b-decode-sw h5-twin-sw h8-stall-nosw
```

Сценарии и правила вердикта — в `runner/scenarios/`. Результаты на текущем коде без правок —
`results/2026-10-27/`. Если вы поменяли детекторы или правила вердикта, пересчитайте
существующие прогоны без перезапуска: `node runner/reanalyze.mjs results/<папка>`.

## Ограничения, которые нельзя нарушать

См. README, «Правила сбора данных»: не извлекать прямые ссылки на видео и не декодировать
обфусцированный скрипт embed, не коммитить сырые записи трафика (только через
`scripts/redact.mjs`), не нагружать CDN сайта.
